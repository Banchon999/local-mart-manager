# 🏪 Local Mart Manager — ระบบจัดการร้านค้าขนาดเล็ก

เว็บแอพจัดการร้านค้าแบบครบวงจร **ไม่ต้องใช้ server ไม่ต้องติดตั้งอะไรเลย** — เปิดไฟล์ `index.html` ในเบราว์เซอร์แล้วใช้ได้ทันที ข้อมูลทั้งหมดเก็บในเครื่อง (localStorage)

ออกแบบมาสำหรับร้านค้าขนาดเล็ก ที่เจ้าของอาจไม่ได้อยู่หน้าร้านเอง — คนที่ร้านบันทึกการขายง่ายๆ ส่วนเจ้าของดูภาพรวมและตัวเลขได้จากไฟล์สำรองข้อมูล

## วิธีใช้งาน

1. ดาวน์โหลด/เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์อะไรก็ได้ (Chrome, Edge, Safari — ทั้งคอมและมือถือ)
2. เริ่มจากหน้า **สินค้า & สต็อก** → กด "+ เพิ่มสินค้า" ใส่ชื่อ ราคาทุน ราคาขาย และจำนวน
3. เวลาขายของ ไปหน้า **ขายสินค้า** → แตะสินค้า → กด "บันทึกการขาย" — สต็อกและรายรับจะถูกตัด/บันทึกให้อัตโนมัติ
4. อยากลองเล่นก่อน? ไปที่ **ตั้งค่า → เพิ่มข้อมูลตัวอย่าง**

## โมดูลทั้งหมด

| โมดูล | ทำอะไรได้ |
|---|---|
| 📊 **ภาพรวม** | ยอดขายวันนี้ รายรับ/รายจ่าย/กำไรเดือนนี้ มูลค่าสต็อก กราฟ 14 วัน สินค้าขายดี สินค้าใกล้หมด |
| 🛒 **ขายสินค้า** | หน้าขายแบบ POS แตะสินค้าเข้าตะกร้า ตัดสต็อก + บันทึกรายรับ + คำนวณกำไรอัตโนมัติ พร้อมรูปสินค้า |
| 📦 **สินค้า & สต็อก** | เพิ่ม/แก้ไขสินค้า (ใส่ลิงก์รูปจากเน็ตได้) รับสินค้าเข้า (ลงรายจ่ายให้อัตโนมัติ) แจ้งเตือนสต็อกต่ำ ประวัติเข้า-ออก ส่งออก CSV |
| 💰 **รายรับ-รายจ่าย** | บัญชีรับ-จ่ายรายเดือน รายการจากการขาย/รับของถูกลงให้เอง เพิ่มค่าเช่า ค่าไฟ ฯลฯ ได้เอง **ส่งออกรายงานเป็น PDF / PNG / CSV** |
| 🗺️ **แปลนร้าน** | ผังร้านมุมสูง (bird's eye view): วางชั้นวางของ ตู้แช่เย็น ตู้ไอติม ตู้แช่แข็ง เคาน์เตอร์ ฯลฯ ลากจัดตำแหน่งได้ ผูกสินค้ากับชั้น/ตู้ แล้วเห็นจุดเตือนบนผังเมื่อของใกล้หมด |
| 👥 **พนักงาน** | ข้อมูลพนักงาน จ่ายเงินเดือน (ลงเป็นรายจ่ายอัตโนมัติ) ประวัติการจ่าย |
| 🤖 **AI วิเคราะห์** | **ถาม AI ผ่าน OpenRouter** ให้วิเคราะห์ยอดขาย/วางแผนการขายจากข้อมูลจริงของร้าน + วิเคราะห์พื้นฐานแบบ offline: แนวโน้มรายได้ คาดการณ์สิ้นเดือน สินค้าขายดี/ขายช้า แนะนำจำนวนสั่งซื้อ ฯลฯ |
| ⚙️ **ตั้งค่า** | ชื่อร้าน ตั้งค่า AI (OpenRouter API key + เลือกโมเดล) สำรองข้อมูลเป็นไฟล์ / นำเข้าจากไฟล์ ล้างข้อมูล |

## การตั้งค่า AI (OpenRouter)

1. สมัครฟรีที่ [openrouter.ai](https://openrouter.ai) → เมนู **Keys** → สร้าง API key
2. ในแอพ ไปที่ **ตั้งค่า → ตั้งค่า AI (OpenRouter)** → วาง key → เลือกโมเดล (มีโมเดลฟรีลงท้าย `:free` ให้ใช้โดยไม่ต้องเติมเงิน) → บันทึก
3. ไปหน้า **AI วิเคราะห์** → กดปุ่มวิเคราะห์สำเร็จรูป หรือพิมพ์คำถามเอง เช่น "วางแผนสั่งของสัปดาห์หน้า"

> หมายเหตุ: ส่วน "ถาม AI" และรูปสินค้าจากลิงก์ต้องมีอินเทอร์เน็ต — ส่วนอื่นทั้งหมดทำงาน offline ได้ปกติ · API key เก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น

## การสำรองข้อมูล (สำคัญ!)

ข้อมูลเก็บอยู่ในเบราว์เซอร์ **ของเครื่องนั้น** เท่านั้น ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะหาย

- ไปที่ **ตั้งค่า → ดาวน์โหลดไฟล์สำรอง** เก็บไฟล์ `.json` ไว้ (แนะนำทำทุกสิ้นวัน)
- ย้ายเครื่อง/ส่งให้เจ้าของดู: เอาไฟล์นั้นไปกด **นำเข้าไฟล์สำรอง** ที่อีกเครื่อง — ข้อมูลจะเหมือนกันทันที

## เทคนิค

- HTML/CSS/JavaScript ล้วน ไฟล์เดียว ไม่มี dependency ไม่ต้อง build
- ใช้งาน offline ได้ 100% รองรับมือถือ (มีแถบเมนูด้านล่าง) และโหมดมืดอัตโนมัติ
- ส่วน "AI วิเคราะห์" เป็นการวิเคราะห์เชิงกฎ (rule-based) จากข้อมูลขายจริง ทำงานในเครื่องทั้งหมด
